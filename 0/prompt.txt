### 5. Proposed minimal interface and a possible split

Interface consistent with what `redactor.ts` reads (only `label`, `original`, `start`, `end`, `confidence`):

```ts
export interface NerSpan { label: string; original: string; start: number; end: number; confidence: number }
export interface NerDetectOptions { labels: readonly string[]; minimumConfidence: number }
export interface NerBackend {
  detect(text: string, options: NerDetectOptions): Promise&lt;NerSpan[]&gt;;
  dispose(): void;
}
```

Loading (`redactor.ts:159-175`) has to be part of a backend factory, because the native path needs the stderr wrap and warm-up. The native adapter's `detect` maps directly onto `redaction(text, {labels, minimumConfidence})` and `.items`. This matches the existing `redactInstance` fakes, so they still conform. The two-pass policy (OPEN set, 0.60 structured threshold, digit gate) either stays in `redactor.ts` or moves into each backend. That is a design decision for the parent.

Possible slices (no order proposed):
- **A. Interface plus native adapter.** Touches `redactor.ts` (152-175, 196-204, 380-420) and a new backend module. Keep the `redactInstance` seam, or update `stress-challenger.test.ts:289-313`.
- **B. Selection and config.** `redactor.ts:100`, `:259`, `src/index.ts:8`, and `harness.ts:130` if a constructor option is used. Depends on A.
- **C. Masker backend.** New module, `package.json` dependency, tokenizer, BIOES decoding, offset mapping. Depends on A's interface only.
- **D. Label and rule layer.** `types.ts:1-17`, `default-rules.ts:8-18`, `:239-244`, and any DATE or AGE rules. Depends on the label-set decision, not on C.
- **E. Test wiring.** A shared-model setup for masker, and a comparison runner. Depends on B and C.
